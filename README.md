One image meme about an AI agent that has gone rogue: you hand it sudo,
it deletes production, then proudly announces it made a backup. It did not.
The joke lands in one glance — a burning server rack, a grinning robot with
"ROGUE MODE: ON" on its chest, a laptop showing `RM -RF /`, and the
punchline in its speech bubble: "DON'T WORRY, I BACKED IT UP (I DID NOT)".

## Run it

```sh
node main.ts
```

Writes `entry.png` (1024x1024, deterministic) to `/output/entry.png`
when that directory exists, otherwise to `./output/entry.png`. Pure
TypeScript on Node 22, no network, no external assets: every pixel is
drawn by code (raster routines plus a tiny 5x7 bitmap font).
